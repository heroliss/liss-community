# v56 · 玻璃去接缝、切角导光与浅色透光

## 修正：玻璃正面的斜向接缝

晶透玻璃卡片在 Chromium 中有一条从左上角斜穿到右侧切角下端的明暗分界。逐层对照确认：只要模糊正面（`material-base` 的 `backdrop-filter: blur()`）位于 `preserve-3d` 外壳内就会出现。去掉 3D 倾斜、裁剪、遮罩或全部兄弟层都不能消除；只用 `saturate()` 不出现；外壳改为平面合成后消失。阅读页的大玻璃面板在 3D 外壳下还有一道模糊暗带，同样随之消失。

玻璃外壳现在使用 `transform-style: flat`，卡片本身仍随指针倾斜。外壳内各层改为按 DOM 顺序绘制，因此高光边 `material-rim` 用 `z-index` 留在 WebGL 涂层之上。倾斜 14° 的对照中厚度观感基本一致。水面材质有独立的反射设计，本轮不改。

## 增强：沿真实轮廓的边缘导光

`community-surfaces.js` 解析玻璃正面计算后的 `clip-path: polygon(...)`，每次绘制时转换为最多 8 条外法线边，作为 `uEdges` 传给着色器。磨砂玻璃的 `inset(... round ...)` 和解析失败的情况，继续使用原圆角矩形轮廓。

- 斜面法线和原有高光按多边形有向距离计算，切角边也能接到主光。
- 新增导光：朝向左上主光的边会在约 6–10px 内返回一条暖白亮带，背向主光的边折射出一道冷暗带。两者都在边缘约 10px 内衰减，不改变正文区域的反射预算；磨砂和浅色模式下更弱。

涂层仍只在姿态、主题或布局变化时绘制（最高 24fps，最多 6 张），只是每个片元多了一个 8 次的轮廓循环。没有新增图片、上下文、动画循环或合成层。

## 浅色晶透玻璃

正面白色遮罩由约 74% 降到约 70%，模糊由 4px 增加到 6px，透出的背景色和纹理多一些。磨砂与手机端参数不变。

在 ink-lake、moss-stone、obsidian-dunes 三张最暗的背景上实测：正文对比度不低于 7.1，次要文字 `#3b4a46` 取最暗像素仍不低于 4.5。本轮试过 60% 遮罩，次要文字会降到 3.9，因此没有采用。

## 镜面与水面

- 水面外壳同样改为平面合成：它的正面也有 `backdrop-filter`，在 3D 外壳里有同类接缝风险；倒影、波纹与涟漪层用 `z-index` 保持原来的上下顺序，画面与改动前逐项一致。
- 涟漪由一道断续的椭圆改为三道依次扩散的同心环，每道都是亮的波峰挨着暗的波谷，内环带一点高光。不再在涟漪里使用 `backdrop-filter`，移动时不需要重新取样背景；最多两组同时存在，约 1.9 秒后移除。浅色模式使用对应的浅色波峰。
- 镜面倒影不再向边框淡出：倒影铺到边缘并略微增强，正文区域仍由下方较暗的底面保证阅读。另加一层很淡的错位副像，模拟背银镜子玻璃前表面的第二次反射，随同一视差移动。

## 验证与边界

- 截图：使用本机 Chrome 无头 GPU 模式、1440×900、2 倍像素、固定背景，对比改动前后、明暗主题、晶透与磨砂、阅读页和悬停倾斜。
- 合成层：首页改动前 553 层，改动后 556 层，基本不变。改平是视觉修复，不作为性能提升。
- 帧时间：滚动时没有观察到变差。rAF 间隔测不到合成器的模糊开销，因此不据此宣称提速。
- 结论只来自 Windows 桌面 Chromium，不能推断 Safari、Firefox 或真实手机上的效果。
