# v26 · 连续的材质与舒缓的场景

最终浏览器与独立汇总均通过，完整证据见工作区 `verification/site-next/v26/acceptance-summary.json`。正常预览为 `http://127.0.0.1:8896/?preview=v26`，独立31篇只读演示为 `http://127.0.0.1:8897/`。

本轮继续在 `design/community-reading-room` 分支进行独立预览，以 `community-v25-preview` 为对照。以下记录实际实现和保护边界，最终验证的原始状态见末节。

## 材质稳定性与光源

青禾卡片的绿色与灰色有三个相互叠加的原因。首先，旧控制器收到姿态的 `active:false` 后会取消已经排队的必需绘制；法线图刚加载或卡片重新进入视口时，静态着色有可能因此被搁置，直到下次鼠标/滚动才纠正。其次，CSS基础面与GPU使用不同的色素计算，GPU还会先移除85%的底色。最后，通用CSS变量选择器的优先级为0,3，盖过了0,2的材质分支，连材质应有的基础色、厚度和圆角也没有真正生效。

现在默认选择器通过 `:where` 降低权重，玻璃、陶瓷、纸和金属各自的变量能正常生效；以实际计算后的基础色和少量作者色求出一个共用色素，同时供CSS和GPU使用。卡片只在有效图集副本完成后标记为WebGL，重新进入视口和资源到达时的必要静态工作不会再被“姿态已停稳”事件取消；多于图集槽位的脏卡片会有限次排空。绿色玉釉的色调保留，但不再与灰色的另一套材质来回切换。原始v25竞态的失败演示与新控制器检查都单独保留。

光影改为固定房间方向的上左主光与较弱环境补光。鼠标改变卡片法线，而不直接把光源绑在鼠标上；祖先默认姿态也参与缓存的法线变换。侧面、倒角和阴影遵循同一偏向，移除恒亮的双侧宽反射带；陶瓷倒角由15px缩到6px。该模型是有预算的艺术性光照，不是对整个DOM场景做光线追踪。

纸张增加可辨的纤维、柔和对角折痕和局部接收阴影；原生CSS纤维层避免把长文细节全部挤进小图集。微翘边角与偏移后页留在装饰层，不裁切或弯曲实际文字、链接与代码。保留一份共享图集、原生文字、圆角覆盖和23%/77%侧面反锯齿覆盖，没有恢复逐卡背景取景、额外模糊或永久材质RAF。

默认姿态相较v25收敛：前后旋转约为55%、左右约80%、平面旋转约88%；鼠标联动的前后/左右幅度则分别约为原来的120%/115%。滚动引起的前后倾斜也降低，输入、选字和模态锁继续保持稳定。

## 背景与照片

十种程序背景增加长周期、低幅度的原生CSS动画：局部色光缓慢变化、线稿/远山轻移、折面保留原角度微动、轨道只绕行小卫星点，避免转动整个画面。织带Canvas仍只在尺寸或主题变化时绘制，随后移动缓存叶片。Keyframe只改变位移、缩放、旋转与透明度，不逐帧修改渐变、SVG路径或Canvas像素。

装饰动画与主JavaScript绘制循环分别记录；暂停、系统减少动态、减少数据、输入、选字、模态、按压、失焦和文档隐藏都会暂停原有时间线，普通恢复保留动画相位。运行的原生动画仍有合成/GPU成本，毛玻璃也需要跟随它重新合成；JS没有永久RAF不等于整个网页没有动态成本。

照片此前同时受到light图片透明度0.6、整体透明度0.8和白色scrim影响。现在两种模式都保持图片透明度1、无滤镜和正常混合，去掉scrim和照片上的附加几何；所有背景均不再创建背景WebGL。程序绘图仍各有日夜配色。照片上的裸标题采用局部、边缘完全渐隐的暗色读区，composer和讨论入口使用局部内容面，不在全窗口给照片铺白罩。600px以下收敛该读区的水平延伸，避免手机出现横向滚动；没有裁切3D内容。既有AI图源和响应式文件没有重编码。

## 公开身份

“系统身份”来自历史 `account_kind='system'` 内容作者，用来保留站点介绍与旧指南，不是当前可登录站点作者的权限证明。公共页面不再显示这个内部分类，管理页面继续显示，便于辨别历史记录。`is_site_owner` 的真实站点作者仍显示“站点作者”；普通账号和访客的标记也保留。这里没有运行账户合并、转移文章、变更密码或权限。

准备阶段实际 Jinja 检查24个端点/身份组合均通过，覆盖 public/admin 与 owner/account/guest/system。正常预览的完整用户和文章数据保持原状。

## 浏览器验收与性能

以下帧率和p95记录的是仪表化的 `requestAnimationFrame` 回调吞吐与间隔，不是显示器实际呈现帧或GPU耗时的直接测量。材质着色独立限制为约24Hz，DOM和原生背景合成由浏览器调度。

共享浏览器中，首次静态绘制与闲置事件后所有可见材质均已绘制且不再脏；实际变量确认玻璃/陶瓷/纸/金属分别采用24/16/5/11px厚度。原生轨道动画的时间在运行时前进，暂停后保持同一相位；模态与系统减少动态也能暂停。明暗照片均无全窗白罩或图片滤镜，浅色纸张阅读页可读。

真正的390×844、DPR1设备仿真发现并修复了浅色照片标题柔光的横向溢出；修复后文档宽度与可用宽度均375px（另15px为浏览器滚动条）。没有裁剪3D内容容器。早先两张误标手机的截图实际仍为桌面视口，保留为历史，不计入手机验收；最终证明是 `browser-mobile-final.json` 与 `photo-light-mobile-final.png`。
