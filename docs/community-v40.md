# v40 · 评论层次与镜面、水面

本轮继续在现有玻璃主题上整理评论与回复，加入可选的镜面、水面材质。修改在本地开发，没有部署正式站，也没有修改玻璃海项目。本地预览地址为 http://127.0.0.1:8896/；启动方法见 [README](../README.md#运行)。

## 评论与引用的层次

讨论区开头使用对话图标、标题和数量，移除额外的说明段落。头像中的文字保持正向；作者名本身已经显示“访客”时，不再重复添加同文徽标。评论使用紧凑的玻璃气泡，头像、作者和日期对齐，正文优先于辅助操作。

桌面上的定向回复只缩进一级，原句引用放入独立的固定右栏，不随短气泡的宽度左右漂移。手机把引用压成更轻的一行摘要，展开内容显示在正文之外；继续回复同一串对话不会不断加深缩进。

引用默认展示简短摘要。展开预览最多两行，服务端摘要最多 180 字符并保留省略号，完整原文仍在原评论中。第一次点击“原句”展开预览与关联连线，保持阅读位置；再次点击才定位原评论。目标不在当前分页或未启用 JavaScript 时，原生 `/comments/<id>` 链接进入原评论所在页。引用内容经过文本提取和 HTML 转义，代码示例不会作为可执行标记插入预览。

点击空白可收起引用、连线和回复输入区域；拖选文字、操作控件、输入法组合及提交忙碌期间受到保护。Escape 先收起引用，再收起编辑器。定位后可返回先前阅读位置，减少动态模式关闭相关过渡。

## 更轻的输入与发送

输入与“发送”横排，输入框从 44px 随内容增高，最高 176px，长文在框内滚动。草稿说明简化为“草稿自动保存在此浏览器”。输入区与评论使用柔和的面状反光、边线和轻微悬停反馈；移除了跟随鼠标的窄亮条，正文和头像文字保持稳定。

收到匹配当前身份、回复目标及提交凭据的成功回执后，编辑器在内容已确认清空的情况下自动收起，并显示“已发送”。请求期间继续输入、删改后恢复原文字或仍在输入法组合时，保留新草稿并保持编辑器展开。发送失败、超时或回执无法确认时也保留文字；不要在未检查最新评论前反复重试。

点击回复、切换草稿、收起及成功发送都尽量保持当前可见评论的位置，不自动把用户带到新评论。服务端分页统一使用时间升序、ID 升序（ASC），空时间戳排在最前；异步发送成功后也统一追加到当前评论列表末尾，避免刷新前后顺序相反。原评论定位使用同一排序规则计算分页。

## 更透明的页脚

页脚保留全宽、紧凑和与顶部呼应的对齐，以 `@Liss` 取代结束语；存在站点作者时链接到实际作者主页。保留“发文指南”“探索作品”等实用入口。

背景从页脚上方 112px 开始铺设宽渐变，由透明缓慢增加到低浓度底色，取消整条背景模糊形成的硬边。分隔线向两端淡出，深浅主题、照片背景和强制颜色模式保留对应文字与焦点样式。

## 十种具体材质

文章外观共有十种具体材质和 `auto`，共 11 项选择：

| 保存值 | 界面名称 |
| --- | --- |
| `glass` | 晶透玻璃 |
| `frosted` | 磨砂玻璃 |
| `ceramic` | 温润釉面 |
| `paper` | 纸册 |
| `metal` | 石墨金属 |
| `leather` | 皮革 |
| `cork` | 软木 |
| `slate` | 岩板 |
| `mirror` | 镜面 |
| `water` | 水面 |
| `auto` | 随站点安排 |

镜面使用镜边、轻微细划痕和随鼠标偏移的场景反光。水面结合透明背景、天空色反光、少量浮屑及鼠标移动或点击产生的涟漪。文字和按钮处于独立的阅读层，反射中不会重复出现文章内容。新建、编辑和项目讨论沿用原有权限、CSRF、写入配额与事务保存外观；选择镜面或水面后可保存并再次编辑。

反光使用当前同源背景图的映像、程序背景配色及备用天空渐变，水下透视来自浏览器的背景滤镜。这是模拟环境反射，没有进行真实光线追踪、页面截图或物理水体计算。本轮只新增这两种可选材质，没有把反射统一叠加到纸张、软木等其他材质上。

反射控制器只在鼠标偏移尚未稳定时请求动画帧。每张水面最多保留四个涟漪，移动距离与时间间隔限制重复创建，动画完成或超时后移除节点。离屏、页面隐藏、粗指针、减少动态和强制颜色模式会停止或复位交互。材质切换与节点移除会清理对应表面的监听器和装饰节点，脚本重复加载会销毁旧控制器及其观察器；页面离开时暂停，返回后恢复适用的表面。实现中的这些限制不等同于已测量的 GPU 成本或 FPS。

## 存储升级与保护

新增迁移 `20261031_reflective_materials` 跟随 `20261031_discussion_replies`，把既有九项材质约束扩展为十一项。普通 Alembic 部署应先备份，再执行完整迁移链。

持久 `public-demo` 准备流程可识别历史五、八、九项约束，先创建 SQLite 一致备份，再直接升级为十一项；已有新约束不会被旧准备入口缩窄。迁移保留已有文章、外观行、索引和所属外键级联关系，复制失败回滚，未知约束停止并留待检查。

如果已经保存镜面或水面，降级会明确拒绝收窄约束，不自动改为其他材质或删除记录。应先明确更换这些文章的材质，或按既有恢复流程使用经过验证的备份。升级和回退前继续保留原数据目录、固定密钥与身份配置，完整说明见[外观与迁移](post-appearance.md)。

## 验证范围

`tests/test_thread_presentation.py` 检查真实回复页面与异步片段的短摘要、原文链接、HTML 转义和精简文案；讨论与草稿回归覆盖分页定位、权限、提交回执和草稿隔离。`scripts/tests/thread.test.cjs` 检查发送后收起、请求期间继续输入、原地操作和追加顺序。页脚、文章外观与反射迁移各有独立测试，`scripts/tests/reflections.test.cjs` 检查实际反射控制器的涟漪上限、偏好变化和生命周期。

在仓库目录可运行统一检查：

```powershell
.venv/Scripts/python -B scripts/check.py
```
