# v23 · 晶透交流展厅

此版本沿用原生 Flask 路由、权限、分页、Markdown、CSRF、配额和表单。正式站没有部署，v22 对照节点保留在 `community-v22-preview`。

## 空间与阅读

背景、帖子流、阅读和写作共享透视、光源和玻璃语汇。背景使用真实 WebGL 网格，玻璃曲面、接收阴影的地面与镜像构成空间；文字、图片和操作仍是原生 DOM。阅读区采用打开的玻璃书页，写作台保持稳定平面，附近的立体构件承担运动。

实图迭代中，多个圆环、翼片和辅助台的叠加显得杂乱，后续收敛成更少的主形体，并移除路由层重复的圆环和整片辅助台。保留中央安静区域，主体靠厚边、遮挡、折光和受光方向表达纵深。

最终使用一幅 AI 生成的欧泊矿物岛屿艺术远景：水面、薄雾、青紫与琥珀透光进入原有远景层及玻璃折射采样。WebP 保留 1672×941 构图，质量 84，153,710 字节；原 PNG 留在验证目录。一次异步解码后缓存，未增加全屏缓冲。三维几何作为低强度陪衬。关键小字使用安全白色，局部柔和遮光保持操作清晰；长文引用的字色也独立加强。

头像降到接近卡面的高度，署名、标题、摘要与图片采用紧凑的层高关系。图片的实体底边与接触阴影、文字的固定投影保留空间线索；输入控件与长文保持稳定清晰。手机单独编排，不把桌面透视机械缩小。

按后续反馈，默认及鼠标联动的前后俯仰收小 25%；左右旋转与横滚保留。

## 晶透玻璃与稳定随机色

自动材质统一呈现为晶透磨砂玻璃，其他材料保留作者主动选择。较低的表面吸收、背景模糊、真实法线与粗糙度、Fresnel 趋势、环境窗反射和邻近背景的窄边采样共同表现玻璃。它仍包含美术近似，不是任意网页元素的物理光线追踪。

没有手选色的文章，根据作者与文章标识稳定混洗六种经过约束的色调。刷新不会换色，列表、详情、回复保持一致；作者选色优先。这个规则只影响展示，不批量写入外观表。原始 `post_appearance`、`page_theme` 返回契约保持不变，新 display helper 单独处理展示。编辑中的“恢复自动”可预览已有文章的自动色，原生 HEX 字段仍保持空值。

## 性能诊断

第一轮七个可见玻璃实体、鼠标与滚动的桌面短测约 58.7fps，缩减背景像素后一次测量仍只有 42.5fps。仅靠降低几何数量或分辨率不足以解释和解决问题。

临时停用逐帧文字阴影曾得到约 109.9fps，但并行完整测试、首次可见卡片与缓存暖机是混杂因素，不能把单次速度变化独占归因。源码仍改为固定投影随 CSS 3D 实体运动，避免每次鼠标更新重新绘制文字；正常几何旋转、材质光照和背景视差保留。

艺术背景版本的冷首轮约 53.7fps、P95 48.5ms；相同路径在暖机后约 108.7fps、P95 14ms、最长 21ms。暂停重复边缘滤镜约 99.9fps，恢复后约 106fps，未支持删除滤镜，因此恢复原样。记录同时保留较慢样本，不把短时暖机成绩当作所有设备或首次进入的帧率保证。

最终冻结源码另外两轮为 65.8/67.5fps，帧间隔 P95 均约 27.9ms。可见暖机短测本身也有波动，不能声称恒定百帧。最终记录以这两轮及完整历史样本为准。场景停稳后，在同一浏览器调用内确认连续无待绘制帧，再观测 1.1 秒，场景、合成和材质均为零新增绘制。

离屏微基准还比较过共享 SDR 中转缓存：直接采样平均约 4.325ms，中转约 4.625ms，因此没有加入这个未经证实的“优化”。重复 backdrop 滤镜是潜在成本，当前保留透明效果，优先修复已有因果证据的文字重绘。

背景低频合成受独立像素预算约束，文字、边框与图片保留原生分辨率。材质共享一个 atlas，场景使用另一个 WebGL 上下文。静止、减少动态、暂停、页面隐藏和输入焦点均按原有生命周期处理；不会为噪声保持永久动画。

## 色阶与 HDR 边界

最终背景协商 `sRGB / float16`，实际读取上下文属性确认生效；不支持时回退普通通道。着色器和最终合成加入固定、低强度抖动，减少平滑色带的量化痕迹，不在文字上叠动态噪声。

当前内置浏览器报告 HDR/P3 能力，浮点画布也确实保留了大于 1 的通道值；但请求 extended tone mapping 后，实际属性仍返回 `standard`。本版本因此明确记录 `hdr:false`，不把广色域、内部浮点精度或硬件能力当作真实 HDR 输出已经实现。

Canvas 的 `colorType` 和 `colorSpace` 是独立配置；`dynamic-range` 也只检测能力，不证明 HDR 已激活。参见 [MDN Canvas 上下文说明](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext)与 [MDN dynamic-range 说明](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/dynamic-range)。
