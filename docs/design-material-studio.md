# 交流工作室 v20

2026-10-30。将论坛的空间表达从单张卡片延伸到背景、帖子流和回复。保持深色基调、原有文字和实际功能，使用烟青玻璃、绿釉陶质、暖灰纸册和石墨金属，配合有远近关系的弧形结构、悬轨、地面光与接触阴影。

## 内容与材质

帖子由固定 ID 选择五套默认姿态，X/Y/Z 朝向和轻微偏移各异，翻页、重载和历史返回不会重新随机。项目讨论使用石墨金属，其余帖子在玻璃、纸册和陶质之间形成稳定节奏。回复按作者稳定区分材质与姿态，较长回复采用更不透明的陶质面；保持原有顺序，不引入虚构的回复树或左右收发关系。

每张面板有单独的背面、侧面、上下厚边、正面、边缘高光和掠光。玻璃约 14px、陶质 12px、纸册 6px、金属 9px；回复和小屏更薄。不同材质有不同倒角、光照响应和边缘形态，纸面保留轻微卷角，玻璃和陶质不使用纸折角。

玻璃正面叶节点采用 `backdrop-filter: blur(16px)`，默认深色手机样式为 10px，并结合染色、厚边、局部掠光和错位的边缘采样。边缘折射感为 CSS 近似，不是物理光线追踪。模糊、遮罩和透明度只作用于装饰叶节点，不放在承载内容的 preserve-3d 祖先上。无滤镜支持时使用较不透明的材质底，保证文字可读。

通过受控测试确认了实际背景模糊：临时在背景 canvas 画细条纹，同一玻璃中央区域在滤镜开/关时，相邻像素亮度差均值分别约 0.049/13.10，实际截图像素均值变化约 21.18。测试条纹、滤镜覆盖和暂停覆盖均已重载还原。真实模糊不依赖“仅设置透明度”的视觉猜测。

## 场景与运动

背景用三张缓存的透明深度图层合成：远处短弧和散焦光雾、中景厚弯带、近处悬轨与柔和地面。不同图层以不同幅度响应鼠标和滚动；近景少量 DOM 曲面与同一组背景变量联动。外围结构可见，中央阅读和桌面侧栏后方使用软过渡压低对比，没有限定内容宽度的矩形背景边界。

背景只在尺寸、主题变化时重建几何和散焦缓存。指针帧合成已缓存图像，昂贵 canvas 合成限频，不在每帧重建阴影或 blur。无常驻循环；动效停止后 RAF 归零。桌面 DPR 上限 1.5、手机 1.25，不引入新依赖或远程资产。

沿用 [v19 阅读与操作机制](design-reading-room.md)：稳定 host、滚动/入场/鼠标各自拥有 transform；透明辅助平面不接收点击。输入、选字、按下和弹窗时背景冻结；暂停、减少动态、粗指针、隐藏、离屏、重复挂载及缓存返回分别门控与清理。编辑器全屏不受新材质壳或背景包含块限制。

## 验收与保留

本地验收只使用隔离合成库。原回归 223 项运行、222 通过、1 项历史 Selenium 跳过；211 项 Flask/真实 CSRF 检查和 157 项保护检查通过，47 个模板解析通过。后台、测试、vendor、旧行为脚本、原 tracked 数据库本轮不变，旧 v19 六份动效文件保持精确哈希。

首页和正文/回复在 1440、768、390 三种宽度的 6 组最终视图无横向溢出或破图，两位独立看图审查者未发现阻断问题。实际浏览器完成了真实背景模糊、帖子点击、图片前景、写作输入/全屏、选字、暂停、减少动态、粗指针、深浅主题、无脚本、重复初始化与历史返回检查。隐藏和 persisted 缓存恢复分支另以已还原的合成事件验证，未声称跨浏览器或真实触屏手势已覆盖。

本机当前 Chromium 的 3.2 秒混合鼠标/滚动与回稳采样约 138fps，P95 帧间隔 7.1ms、最大 27.7ms，驱动回调最大 7ms；回稳后一秒 RAF 回调和背景绘制均为 0。这是一次包含回稳的本机场景采样，不是持续满负荷或所有设备性能保证。

逐项结果、截图与采样保存在工作区 `verification/site-next/v20/`。Taste 对材质渐变以及 Impeccable 对叶节点局部高光的提示原样保留，未改写为全部通过；这些材质表达遵循用户明确要求，而技术检查与人工实图审查单独记录。

预览分支继续使用 `design/community-reading-room`，保留 `community-v19-preview`，新版节点为 `community-v20-preview`。作品站 v18、原站与旧版对照不变；本次不部署线上，不修改生产数据或身份设置。
