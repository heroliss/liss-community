# v25 · 清晰的边缘、慢一点的远景

此版本继续在 `design/community-reading-room` 分支预览，基线为 `ed84d38819f5a5672c1bb2b1f7b0809eb83addcb`。v24 保留为 `community-v24-preview` 对照节点。本轮不改账号、文章、评论、外观存储、权限、配额、后端路由、原测试或数据库结构，也不部署正式站。

## 卡片轮廓与两种光环境

卡片本身是浏览器原生 CSS 三维平面，材质 atlas 渲染的是覆盖在它上的反射与细微表面。单纯给这个全屏四边形 atlas 打开 MSAA，不能替浏览器的 DOM 卡片轮廓完成多重采样。

新版在现有 shader 中加入圆角距离场与小数像素覆盖率，按卡片实际四角半径及 tile 尺寸计算，软边限制在约 0.65–1.35 CSS px。实际逐层隔离截图发现，明显的阶梯轮廓主要来自接近侧视的窄侧壁。最终只在这些空侧壁的局部深度两端渐隐：23% 以内进入实心、77% 后退出，保留中间 54% 的实心部分；24px 厚、80° 侧壁的每端覆盖带投影约为 1 CSS px。

早期尝试的侧壁 0.24px 与后板 0.25px blur 均已删除。隔离与后板对照分别留在 `aa-full-layer-isolation.png`、`aa-back-filter-comparison.png`，没有把未解决主要轮廓的临时滤镜当成最终修复。后板保留透明 outline，正文、图片像素、光标、输入面与三维父层不加模糊；原生玻璃面也没有再叠一层 filter。

这是一组针对现有阶梯边缘的覆盖率与局部软化改进，不是一个能保证所有浏览器、角度和像素密度绝对无锯齿的 DOM MSAA 开关。没有扩大材质 atlas、增加逐卡 GL、恢复宽景物镜框或重建逐卡取景。

暗色仍是主要光环境，保留玻璃薄倒角、80° 斜切侧壁、局部反射和接触阴影。浅色则有单独的银青色吸收、侧壁、回光和接收阴影，替换先前写死的近黑侧色。首页、侧栏、登录/资料铭牌等浅色标题同时减轻重黑投影，浅色正文不沿用暗色的白字发光。

陶瓷、纸、金属分别保留釉面宽高光、薄纸纤维与层叠边、定向拉丝反射；两种光环境各有对应底色与侧光。其阅读区域按实际文字颜色限制表面亮度，不通过统一玻璃透明度掩盖材质差别。头像仍贴近卡面，只调整局部边光和接触阴影，不重新把头像抬出卡片。

## 十种本地绘制背景

| 选择 | 绘图方式 | 内容与色彩密度 |
| --- | --- | --- |
| 柔光留白 | CSS 柔光色域 | 很少内容，灰青留白 |
| 流线素描 | SVG 三次曲线 | 稀疏流线，少量冷暖色 |
| 山形等高 | SVG 地形路径 | 中等密度的等高线 |
| 棱镜折面 | CSS 裁切色面 | 冷暖切面与细折痕 |
| 轨道手记 | SVG 椭圆、弧与刻度 | 非对称的空间轨道 |
| 纸间山丘 | CSS 纸层与投影 | 低彩度的纸景浮雕 |
| 流彩织带 | Canvas 2D 曲线与渐变 | 更丰富的宽色带 |
| 星图余白 | 固定种子的 SVG 星点 | 稀疏星图，不闪烁 |
| 柔彩色域 | 多层 CSS 色域 | 更宽的色彩范围与柔和留白 |
| 层峦暖沙 | SVG 有机轮廓 | 暖沙与远近不同的山脊 |

程序背景不请求照片，也不创建背景 WebGL。CSS 与 SVG 直接由浏览器按当前显示密度绘制；织带 Canvas 只在尺寸、DPR 或主题变化时重画，最多 2.4MP、最多 2× 比例，画的是宽色带，不承载细字。切换后释放其像素存储，Canvas 不可用时退回可读的 CSS 色域。各款不是同一个图形换颜色，也没有为背景启动永久计时器或逐帧像素动画。

选择器分开列出本地绘制与图片选择，使用原生 radio 和对话框，保留键盘、Escape、焦点返回和 v24 已存的偏好。预览缩略色块由 CSS 绘制，不触发对应大图下载。

## 长卷只以页面速度的 5.5% 展开

旧实现把整篇文章的滚动进度映射到长图所有可用裁切高度，文章越短，画卷相对越快。新偏移为 `min(可用裁切高度, 页面绝对滚动像素 × 0.055)`：页面移动 1000 CSS px，画卷约移动 55px，另有很小的相机位移。它不再承诺一次阅读展示完整长图。

固定像素速度也避免文章插入内容、展开写作区或重新计算总高度时改变进度比例。关闭背景滚动、暂停、系统减少动态、输入、选字和模态锁继续受到尊重，原生图层保持高清，不重复尾部或超出有限裁切范围。

## 新帖起点与旧帖展示

新建文章或项目讨论时，原生外观字段会得到一次随机的协调色和材质，颜色与材质仍可手动修改。十二个克制色和加权材质池让玻璃约占一半，其余可选陶瓷、纸、金属；没有新增随机按钮或随机提示。选中的值与原生默认值同步，重置、撤销与正常提交有一致的起点。

只有 GET 的新建空表单、空主题色和 `auto` 材质且没有恢复正文时才初始化。编辑既有文章、POST 校验回显、恢复的草稿或手动外观不会重新随机。无脚本时原生字段与原有自动回退仍可使用，不改变服务端保存规则。

对于原来没有明确材质的旧 `auto` 文章，只做稳定的展示搭配：按 ID 的八个位置，五个玻璃，陶瓷、纸、金属各一个。首页顶部、文章流、详情、作者页与编辑预览共用一个 Jinja 宏；展示不会生成外观记录，也不把编辑表单的原生 `auto` 改成其他保存值。任何明确保存的材质都优先，尤其保留现有文章 12/13 的玻璃设置。

暂停按钮现在同时同步播放/暂停 SVG、文字、标题与无障碍动作名；页头、页尾、跨标签存储和页面恢复采用同一条状态路径。系统减少动态时按钮禁用并解释原因。侧栏的作品入口改为由拱廊、台座、切面体、代码物件与轨道组成的小型展厅，保留一个明确的“进入作品展厅”链接，不再用几块空白玻璃叠片暗示内容。
