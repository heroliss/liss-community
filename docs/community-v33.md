# v33 · 写作保护与持续交流

本轮沿用 v32 的场景、材质、图片查看及原生页面导航，完善写作与论坛交流。范围仅为社区应用，不修改玻璃海或作品站构建。

## 使用变化

- 文章与项目讨论的写作台按用户 ID、页面路径保存本机草稿，包含正文、颜色和材质。刷新后恢复；已有服务端正文冲突时由使用者选择。舍弃后可撤销，存储不可用时明确提示。离开有修改的写作页触发浏览器原生提醒。服务器提交成功后只清理该次提交对应的草稿，保留其他身份、页面和较新的稿件。
- 导航“搜索”支持查找公开文章正文，关键词按文字匹配；隐藏内容不出现在结果中。搜索支持分页、空结果和长度错误提示。
- 评论“回复”明确指定对象，保存父评论关系。新评论提醒文章作者；定向回复只提醒目标评论作者，自己回复自己不提醒。账户菜单显示未读数，“回复提醒”仅本人可见；查看回复通过带 CSRF 的 POST 标记已读，再定位到对应分页和评论。
- 本人可修改评论正文，作者、发布时间、回复关系保留并显示“已编辑”。修改不重复发送提醒，其他人及管理员不能借此入口改写他人的评论。
- 明亮照片上的匿名讨论邀请、新搜索与提醒页的标题和状态文字使用稳定表面承托；保留深浅主题和材质风格。

本节记录 v33 的历史范围，当时普通评论输入框尚未接入草稿控制器；[v34](community-v34.md) 已补齐普通评论、定向回复及编辑评论的草稿。草稿保存在当前浏览器设备，不等同于跨设备同步或服务器备份。

## 资源与维护

25 份主要 CSS 按原顺序合并为一个压缩、内容哈希资源；新增讨论样式独立。第一方 JS 按通用、图库、写作、身份页等分组，图库和编辑器按页面加载。保留源文件便于维护；运行时验证源码及生成物哈希，产物过期时回退到当前源，避免悄悄运行旧包。背景和 WebGL 材质纹理均兼容打包目录与应用前缀。

当前主样式输入 394399 字节，生成物 353102 字节；构建工具估算 gzip 为 60503 字节。它们是文件和压缩大小，不是正式站网络传输或低端设备性能指标。

`scripts/check.py` 统一执行生成物检查、Python/JS 语法、真实控制器 VM 和 Python 回归。CI 对 Python 3.13/3.14 与 Node 24 执行同一门禁；保留完整日志，不自动部署。独立快照升级演练、HTTP 烟测和启动入口见[检查与发布指南](testing-and-release.md)。

## 数据与发布边界

增量迁移 `20261031_discussion_replies` 新增评论父关系、编辑时间及通知表，升级前通过 SQLite backup API 保留安全快照。旧内容、身份、用户 ID、密码和会话代次保持。预览使用独立存储与密钥；8896 兼容既有预览 Cookie，其他端口使用不同 Cookie 名，避免同时验收时串登录状态。

分享元信息包含公开文章独立标题、纯文本摘要、canonical 与可用封面。公开域名来自固定配置，拒绝使用请求 Host 生成分享 URL。默认关闭搜索收录；只有明确设置 `LISS_INDEXING_ENABLED=1` 和正式 HTTPS `LISS_PUBLIC_BASE_URL` 后，公开页面才允许收录，并提供分片 sitemap。预览、账号、后台、编辑、搜索及错误页保持 noindex；隐藏文章不进入 sitemap。

完成本地源码与隔离数据验收不等于正式站发布。真实手机触屏、中文输入法与软键盘、Firefox/Safari、低性能硬件及邮件实收仍需相应设备和服务上的验收；本机 Chromium 视口模拟不能替代它们。正式发布还需原站一致备份、副本演练与发布后验证。
