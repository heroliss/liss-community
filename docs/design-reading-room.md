# 立体阅读室 v19

2026-10-30。保留石墨深色、暖白正文与薄荷色操作，以及可选浅色。此次改版把空间感从页头延伸到阅读、回复、身份和写作，按内容的用途安排不同的立体表达。

| 内容 | 空间表达 | 操作原则 |
| --- | --- | --- |
| 帖子流 | 有书脊、侧缘与掠光的悬浮刊物 | 标题、评论、全文仍为原生链接 |
| 正文 | 安静的阅读槽、渐隐弧面边缘 | 长文旋转按高度衰减，装饰不干扰阅读 |
| 评论 | 连续时间脊、作者圆章、轻微卷角 | 按作者固定细微色调、错位与前后距离，不暗示回复树或左右收发关系 |
| 写作 | 正面的稿纸与后方立体写作台 | 输入、IME、工具栏与提交位置稳定，全屏释放三维包含块 |
| 图片 | 保留自然比例的独立展面、真实侧缘 | 封面仍进入帖子，正文图片可展开，原链接用途保留 |
| 身份与侧栏 | 浮起的头像封印、弧背和短悬托 | 身份与主操作清晰，辅助装饰不接收点击 |

精细指针下，图片可达约 ±8°/12° 的 X/Y 互动旋转，帖子约 ±6°/9°，回复约 ±5°/7°，页头约 ±8°/12°。实际值依据内容高度和鼠标位置衰减，默认姿态与鼠标增量分开。短文本控件 hover 时保持当前姿态，图片区域继续追踪；按下、选字和输入时冻结相应平面，不突然归零。滚动层、有限入场层和鼠标层分别拥有 transform，使用同一阻尼控制器，避免重复缓动。

透明的相机、滚动和入场辅助平面不参与鼠标命中，由实际内容 surface 接收事件，解决倾斜平面的负 Z 半面被透明父层挡住的问题。图片保持完整画幅，无额外“放大”覆盖文案。原生 dialog 提供键盘焦点、Escape 和关闭后的焦点归还；开合使用 420/240ms 空间过渡，查看器内部有独立鼠标透视。

同源帖子打开和返回使用原生跨文档 View Transitions，标题、图片和导航拥有临时唯一名称；根场景约 400ms，共享内容约 460ms。不接管历史、链接、GET/POST 或表单焦点。不支持此能力时正常导航。实现依据 [Chrome 跨文档说明](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document) 与 [pagereveal 生命周期](https://developer.mozilla.org/en-US/docs/Web/API/Window/pagereveal_event)，暂停和减少动态时跳过过渡。

页脚可暂停动效，减少动态偏好即时生效。离屏停止更新，隐藏状态暂停，BFCache 返回和重复初始化均清理再挂载，空闲后不持续请求 RAF。粗指针关闭追鼠标，保留正常滚动和较浅的空间层次。无脚本仍能阅读、展开原生写作 details、使用 textarea 和提交。

本轮没有新增私信、上传、通知或回复树。56 个原路由、CSRF、权限、Markdown 清理、访客配额、邮箱与账号状态、分页、项目关联及管理行为保持。后台、模型、迁移、依赖、旧行为脚本与编辑器 vendor 未改；唯一测试适配为允许评论 li 增加合法 data 属性，原作者徽章与正文断言保留，并增加唯一目标校验。

验收使用隔离合成账号与 SQLite。原回归 223 项运行、222 通过、1 项历史 Selenium 跳过；补充 211 项 Flask 页面/权限/真实 CSRF 检查通过。108 个受保护文件、56 个路由及原 tracked 数据库经 158 项检查；原数据库与后台哈希保持一致，唯一测试适配按精确哈希单独登记。47 个 Jinja 模板检查通过，4 份前端脚本语法通过。

实际浏览器覆盖桌面、平板和手机布局，完成本地登录、写作、全屏/分屏/预览、发布、评论、图片开合、选字、暂停、减少动态、粗指针门控、深浅主题、无脚本与重复初始化检查。开帖/返回的原生动画已观察执行。当前浏览器 3.2 秒鼠标/滚动采样约 143.7fps，P95 帧间隔 7.1ms、最大 13.9ms；驱动回调最大 2ms，空闲一秒 0 回调。这是本机一次场景采样，不代表所有设备性能。

真实历史前进后退已通过，图片打开时返回也无滚动锁或遮罩残留；此次本地预览未命中 BFCache，其 persisted 分支和隐藏动画门控使用已还原的合成事件另外验证。IAB 不支持原生触屏拖动注入，因此未把真实触屏手势或跨浏览器表现算作已验证。手机尺寸、粗指针状态的显示与正常滚动已检查。Taste 原始报告保留：按用户要求保留的悬浮阴影、材质渐变和大标题会触发默认风格提示，未改写为全绿；6 个最终路由/尺寸视图均无横向溢出或破图。Impeccable 最终渲染扫描无发现，独立看图未发现阻断问题。
