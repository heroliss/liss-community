# v22 · 悬浮交流工作室

此版本重新组织论坛首页、阅读、写作与身份页面。保留 Flask 原生路由、分页、权限、访客配额、CSRF、Markdown 和原有内容；没有部署正式站。v21 保留在 `community-v21-preview`。

## 一间完整的交流工作室

首页由真实最近文章组成前后错落的立体场景，下面是有宽窄、角度和高度变化的帖子陈列。右侧用一座完整的交流控制台承载身份、参与入口与站点介绍，另设作品入口；移除旧的孤立横条和侧栏细支架。

背景为远、中、近三层程序场景与独立前景构件，采用不同的视差和雾化强度。帖子主体、头像、署名、标题、摘要和图片位于不同高度；实体侧面、厚边、接触阴影与局部光照共同表达空间。手机重新编排成独立纵向场景，保留完整标题、表单和操作目标。

原写作区背板在 `translateZ(-22px)` 后继续旋转，长面板的部分顶点会穿过正文的 Z=0 平面，造成截图中的右侧斜切和标题附近细线。v22 将输入区域作为稳定的平面堆叠上下文，装饰底壳置于独立后层。正文、工具栏、提示、配色控件和全屏编辑不再与旋转背板相交。

## 真正不同的微表面

一个共享 WebGL atlas 为可见材质生成微表面结果，再投到 CSS 3D 实体的叶层上。桌面 atlas 为 1024×768，最多六个可见材质槽；手机为 512×512，最多四槽。文字保持原生 DOM 清晰度。贴图由本地程序生成，不依赖外部 CDN。

- 玻璃：透明反射、菲涅耳趋势、实际 backdrop 模糊与背景窄边压缩采样。
- 釉面：法线与粗糙度驱动的 GGX 高光、宽光源反射和圆润厚边。
- 纸册：纤维法线、较高粗糙度与 Oren–Nayar 漫反射。
- 金属：拉丝方向法线与各向异性 GGX 高光。

这是 CSS 实体几何加微表面 BRDF 的 2.5D 界面。玻璃折射、环境反光和柔光箱含美术近似，不是整场景光线追踪。无 WebGL 或无脚本时保留独立的 CSS 纹理材质。

自选色先去除旧固定底色的偏色，再进入各材质色料。限亮采用线性 sRGB 亮度的同比曝光，保留色相，避免逐通道截断把高光压成灰色。读字区根据实际文字角色计算亮度边界；1440 组不透明材质数值样本的最低对比为 4.628:1，主文字最低 8.735:1。该结果不声称覆盖玻璃、装饰边缘和所有抗锯齿像素。

## 从选色到整段对话

选色立即联动页面的背景光、导航、按钮、链接、表面、输入区、边线与预览。保存后，详情和其回复实体沿用同一主题；每个帖子独立拥有自己的颜色，不被其他草稿染色。深浅模式分别生成可读角色色。服务器与浏览器共用整数舍入规则，108 组颜色样本一致。

撤销、恢复自动、关闭写作台或离开页面会清理未保存的页面主题，不修改全站偏好。HEX 与材质仍通过原生表单保存，关闭脚本后可继续提交。原始选色、关联存储与迁移边界见 [文章外观说明](post-appearance.md)。本版本没有新增数据库迁移。

## 展开、返回与身份

浏览器原生页面转场分别匹配当前帖子、标题与封面，展开为阅读场景；返回列表时回收到对应帖子及来源位置。保留真实链接和浏览器历史，不通过拦截表单或客户端替换 HTML 实现导航。输入、聚焦、提交、暂停或减少动态会跳过快照。转场的预期取消拒绝被明确观察，其他错误继续报告。

登录、注册、资料编辑采用立体铭牌、档案层与工作台。输入控件保持平面，鼠标联动由旁边的雕塑承担；名称与简介的本地预览不保存任何数据。手机实图中曾发现雕塑遮住副句，已改为标题、独立场景、说明、表单的正常顺序；桌面底座与铭牌相交也已修正。
