# 背景设置与临时观景

导航栏的「背景」打开正式选择器。按名称、主题或说明搜索，或在「全部」「影像」「绘制」之间筛选；所有图片统一放在「影像」，不再重复设置暗色分组。数量来自当前目录。打开时定位正在使用的背景，桌面显示三列缩略图与设置侧栏，手机显示两列。

草选只更新缩略图和所选说明，不应用偏好或请求该背景的大图。点击「使用这个背景」才保存背景、图片细节和滚动设置；取消保持原偏好。偏好仅保存在当前浏览器。

## 随机背景

首次使用默认开启「来访时随机」，随附51张图片全部参加随机；22种绘制背景仍可手动选择。管理员可以调整站点默认随机开关、名单和可用图片。已有个人自定义名单保留，不因站点默认调整而直接覆盖。

随机只在从外部进入时抽取一次，不是定时轮播。同一次站内跳转、刷新、前进后退和站内打开新标签页保持当前画面；另一个标签页从外部进入不会带动已经打开的页面换图。多个候选时避免连续重复上一张。关闭随机则固定使用所选背景。

「随机范围」中可搜索、逐项勾选、全选、清空和恢复站点默认；应用后才保存，取消放弃草稿。随机开启时不能保存空名单。管理员停用或移除的图片会从可用范围过滤；个人名单全部失效时恢复站点默认并提示。观景左右切换或手动换图只调整当前画面，不会悄悄关闭随机。

当前标签页的画面存于 sessionStorage，个人偏好存于 localStorage；当前画面不会因新入口抽取而写成跨标签共享偏好。存储被禁用时当前页面仍可使用，无法保证跨页面记忆。

## 默认背景方向的新增方案

新增三张图片：静湾流光（`tidal-still`）、雾光庭廊（`satin-atrium`）、烟青曲光（`sea-glass-study`）；以及三组绘制背景：雾织玻璃（`glass-weave`）、银湾回澜（`mercury-tide`）、柔晶层岸（`opal-strata`）。这一批围绕静水、柔和玻璃空间、海玻璃与折光层次设计，目标是兼顾适中的亮度、构图留白和阅读时的丰富度。

水下天光方向另加入三张图片：深水微明（`deepwater-hush`）、暮蓝水镜（`blue-hour-caustics`）、澄青浅影（`quiet-aquamarine`）。这一批围绕稍暗、较纯净的水下光感和低密度折射设计，同样作为可独立选择的图片背景保留，不覆盖当前偏好或指定全站默认。

它们作为正式目录中的可选方案一起预览。当前默认采用图片随机，不指定一张固定默认项。随附51张图片均从保留来源重新经 VOSR2 处理，宽3840像素，提供960/1440/1920/2560/3840响应式 WebP 与缩略图；地月原始照片为缩小后复原，早期长卷使用已认可裁切，不把所有结果声称为原生4K。旧超分结果和原图保留在工作区归档，发布目录只包含当前所需资源。管理员新上传图片仅保留原像素并重编码，不自动调用 AI 超分。绘制背景继续跟随明暗主题、窗口尺寸与动态偏好调整。最终画面的亮度及正文对比仍需结合实际页面检查，色板检查不能代替图片上的阅读验收。

「柔彩色域」原版继续保留。它的两组图案变体「柔彩叶影」（`spectrum-botanical`）与「柔彩浮纹」（`spectrum-ripples`）沿用原有柔紫、绿松与桃色底景，分别加入边缘叶影和宽幅弧片层次；它们属于独立的绘制背景，不改变原版或用户已保存的背景。图案同样响应明暗主题与动态偏好。

设置侧栏底部固定显示「开启观景模式」，不再放入「更多选项」折叠。预览与设置区可以单独滚动，不会把观景入口挤出侧栏。已移除图片技术参数和动态提示等冗余说明，图片细节、滚动设置和必要的来源署名仍保留。

「开启观景模式」应用当前选择并临时显示工具条，提供左右切换、只看背景、背景说明、再次选图和退出。默认页面不显示工具条；刷新、离开页面和 BFCache 返回时均退出。所选背景本身仍按正常偏好保存。

观景面板闲置约 2.4 秒后收成「观景」入口，鼠标靠近即可展开，触屏可点击入口。悬停在面板、用键盘操作或展开背景说明时保持显示，也可手动收起。隐藏的控件会退出键盘焦点顺序；关闭观景后清理计时器、活动监听和待执行的布局帧。

正文模式下，浮动面板与页尾保持 12px 间距；「只看背景」隐藏页尾时回到底部。极矮窗口没有足够空间时先收起，鼠标悬停不滚动页面，主动点击或键盘唤出才轻移到可完整容纳面板的位置。展开背景说明也会检查上方空间，不把弹层挤出视口。

## 生命周期和可访问性

- `liss:background-viewer-open` 开启工具，可携带 `detail.returnFocus`。
- `liss:background-picker-open` 复用选择器，可携带 `detail.returnFocus`。
- 方向键只在观景开启且未编辑输入框、未打开 dialog、没有修饰键或输入法组合时接管；Esc 退出观景。
- 只看背景时保留页面布局以便滚动，同时隐藏正文的视觉、键盘与辅助技术入口。退出时精确恢复先前 `aria-hidden`、`inert`、滚动位置和焦点。
- viewer 的开启状态不写入 localStorage 或 sessionStorage，不创建额外图片请求或动画循环。
- 历史 `scene` 链接仍可选择有效目录项一次，并移除历史评审参数；`background_review=1` 不再开启工具。

`window.LissBackgroundViewer` 提供 `open / close / read / destroy`。背景偏好沿用 `window.LissBackgrounds`；导入目录时复制条目和 variants 后才冻结，重复初始化不污染共享数据。

## 资源与验证

正式功能沿用 `background-review` 与 `background-review-styles` 内部 bundle 组名，但它们现在是默认隐藏的正式观景模块，不再受本地预览开关控制。旧候选列表、待选存储读写、名单导出和 S 快捷键均已移除。

相关行为检查：

```powershell
node scripts/tests/background-picker.test.cjs
node scripts/tests/background-viewer.test.cjs
node scripts/tests/backgrounds.test.cjs
node scripts/tests/background-random.test.cjs
node scripts/tests/background-managed-palettes.test.cjs
npm run build
npm run check:assets
```

Flask 页面与资源检查位于 `tests/test_frontend_assets.py`。原文章自定义颜色、材质和按需图片加载仍需保持。真实浏览器还应检查取消/应用、搜索空态、观景退出与刷新、手机触控和明暗主题。
