# v35 · 双视图文章流与阅读室页脚

沿用阅读室的景深、八种材质、背景和深浅主题。本轮仅更新论坛的本地源码与预览，没有部署正式站，也没有修改玻璃海。

## 文章显示方式

首页、作者主页和项目讨论的文章流可以切换“卡片 / 紧凑列表”。同一份文章 DOM 通过排版规则切换，不复制文章，也不替换原生链接、分页或阅读返回。列表收紧作者信息、标题、摘要和评论入口，真实封面缩为侧边图片，保留各自材质、厚度、悬浮反馈和景深。

有效的本机持久偏好优先于当前标签页缓存；持久存储不可用时仍可在当前标签页切换。偏好在样式加载前读取，避免先展示大卡片再跳到列表。按钮提供按下状态、焦点轮廓与方向键/Home/End 操作。关闭 JavaScript 时保留原卡片。文章详情始终使用正文阅读版式。

切换只以短暂的文字显现反馈提示新排版，不接管页面导航或强制滚动。系统减少动态时关闭切换动效。

## 导航与页脚

移除页眉与页脚的手动暂停入口；背景选择只保留在页眉。旧浏览器曾保存的手动暂停偏好不会再让没有对应控制的页面永久停住，系统“减少动态”仍优先生效，文章跨页过渡与空间动效遵循同一规则。

页脚改为独立的不透明层叠搁板，包含站点介绍、阅读、搜索、作品、写作以及回到顶部。发文指南只在站点明确发布后出现，避免未发布时指向 404。身份区域按登录状态显示访客/登录入口或个人主页、回复提醒、资料与账号保留入口，遵循站点开关和用户权限。手机视口重新排列内容，长昵称与自定义站点介绍可换行。

## 验证

控制器回归直接加载实际脚本，覆盖偏好、跨标签页更新、详情返回后的新偏好、存储异常、键盘、减少动态与页面生命周期；HTTP 模板回归覆盖不同身份、站点开关和路由资源。统一检查入口仍为 `scripts/check.py`。

真实浏览器检查和最终日志位于工作区 `verification/forum-improvements-20261031/v35/`。本机 Chromium 与窄屏模拟不等同于真实手机、Safari/Firefox 或低性能设备验收；本轮没有新增数据库迁移，也未发送真实邮件。
