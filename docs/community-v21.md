# v21 · 连续空间与文章外观

此版本位于 `design/community-reading-room`，使用本地隔离预览。没有部署到正式站，也没有修改原站、作品站或生产内容；`community-v20-preview` 保留作对照。

## 连续的卡片姿态

旧控制器在 IntersectionObserver 再次入屏后，超过冷却时间便重播固定 `rotateX(-2.8deg)` 的入场。这与鼠标及滚动控制器叠加，导致回滚时角度突然复位。v21 将入场消耗记录保存在同一 host 的生命周期内，只首次轻淡入，不再引入第二个旋转来源。原鼠标和滚动幅度保留。

卡片通过共享空间帧驱动背景反向镜头、侧栏支架、工具条底座及回复后层。写作预览保留自己的立体互动，不参与全局镜头主导。滚动预热、选择、输入、按压、减少动态、暂停与销毁逻辑均保留。

## 自由选择，统一呈现

发文、编辑与项目交流表单增加折叠的“文章外观”：六种推荐色、系统颜色选择器及 HEX 输入；材质为自动搭配、磨砂玻璃、温润釉面、纸册与石墨金属。即时预览只使用安全文本，不解释草稿 HTML。

选色保存原始有效 HEX，但展示统一换算为受控 HSL：亮度固定，饱和度限制在 55% 以内，低饱和色保留中性。颜色主要混入实体边缘和局部高光，面内染色不超过 8%，正文底与文字维持共享对比关系。浅色模式另外压低作者名称颜色的亮度。由此保留个性，避免把整面卡片铺成互相争抢的彩色块。

设置通过原表单权限与 CSRF 保存至可选的一对一 `post_appearances` 表。旧文章继续自动搭配；编辑遗漏字段保持已有设置；显式自动配色加自动材质可重置。JavaScript 关闭时，原生色值输入与 radio 仍可提交。严格校验、数据库迁移及回滚边界见 [外观存储说明](post-appearance.md)。

## 玻璃与周边结构

降低整面深色遮盖，用局部柔和阅读暗层保留正文清晰度；背后的场景可以透过玻璃。窄边压缩、偏移采样本站程序背景 Canvas，形成随姿态变化的折射感；这是一种实时界面近似，并非物理光线追踪。纸、釉面、金属保留不同实体侧边与反光。

收窄并压暗帖子左侧的旧浅色轨道，减少亮侧面突出造成的孤立白条。外围支架和地面延续场景纵深，渐隐离开内容区域，避免新矩形底板。

采样只处理可见玻璃，离屏释放为 1×1。缓冲按 64px 桶分配，避免旋转带来的 ±1px 重复分配。大面积光斑保留静态渐变，用 transform 联动，避免每帧重画模糊渐变。背景主画布与三层缓存共限制为 16M 像素；文字和卡片 DOM 不降分辨率。静止后没有持续 RAF 或背景绘制。

## 验证与范围

- 最终完整隔离测试 246 项：245 通过、1 项原 Selenium opt-in 跳过；源码快照稳定。前一轮 245 项执行期间三个 UI 文件继续迭代的报告完整归档。新增专项与相关回归 83 项通过。
- 冻结后页面状态 228 项，保护检查 159 项，独立迁移 6 项通过；浏览器迭代后的最后记录保存在工作区 `verification/site-next/v21`。
- 实际浏览器确认编辑保存、回填、无效颜色拒绝、无脚本重置、全屏编辑、图像展开/关闭、暂停、减少动态及触摸门控。桌面、平板、手机六个页面截图无横向溢出或坏图。
- 外观校验失败会保留同时编辑的正文草稿；不会替换回数据库旧正文。浏览器实际输入和修正后提交均已验证。
- 实际回滚采样 45 帧：没有重播旋转入场，采样最大帧间角度变化 0.30°。
- 当前 Chromium / 1440×1000 / DPR 1 的一次暖机鼠标加滚动采样：约 131.7fps，帧间隔 P95 13.9ms，最长 21ms，采样期间玻璃缓冲重复分配为 0。静止 1.1 秒采样为 0 RAF / 0 绘制。它不是跨设备持续负载保证；优化前的较差原始记录一并保留。

Taste 自动检查仍报告渐变、标题尺度、图标容器等风格启发式项；它们没有被伪装成“全部清零”。本轮明确的立体材质、公共文章标题与空间构造需求保留，实际布局问题以截图复核。正式部署前仍须按原维护指南备份目标存储并执行迁移。
