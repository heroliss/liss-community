名词解释

访客
同一个浏览器算一位访客，即使 IP 变了也一样。同一浏览器在社区和作品站的记录（Chrome 系浏览器）、登录同一社区账号的手机和电脑，会自动合成一位访客；IP 相同不会合并。硬件相同又用过同一网络的，列在“可能是同一人”里，由你确认后合并。换浏览器、用无痕模式或清除全部站点数据仍会算成新访客。
访问次数
一次连续的浏览。离开 30 分钟以上再回来算新的一次。
浏览量
打开页面的次数，刷新也算。
有效访问 / 有效浏览
停留超过 {{ engaged_seconds }} 秒、有过鼠标/触摸/键盘操作或点击，或看了两个以上页面（有效访问）。打开就走的不算。
停留时长
页面在前台、并且最近有操作的时间；切到别的标签页或长时间不动不计入。
滚动深度
页面往下看到了多少，100% 是看到底。
跳出
只看了一个页面就离开的访问。
入口页 / 离开页
一次访问的第一页和最后一页。
新访客 / 回访
第一次来访在所选时间范围内的是新访客，之前来过的是回访。

常见问题

我自己刚看了网站，统计里为什么没变化？
你的访问被归为“本人”，默认视图不显示。筛选栏“类型”切到“本人”就能看到。后台页面本身不记录访问。
刷新统计页会有延迟吗？
打开页面约 1 秒内就会记录，停留时长每 15 秒更新一次。统计页刷新即可看到；“实时”页每 20 秒自动刷新。服务器日志依赖 PythonAnywhere 同步，可能晚几个小时。
为什么很多访问显示“直接访问”？
很多 App、浏览器和网站会隐藏来源。分享时用“来源”页生成的分享链接，就能准确知道是哪次分享带来的。
访客数比实际少或多？
禁用 JavaScript 或屏蔽统计脚本的访问不会被记录；同一个人用多台设备、又没登录社区账号时，会算多位访客（可在“访客 → 可能是同一人”里确认合并）；同一 IP 背后的不同设备不会被算成一位。数字适合看趋势，不必精确到个位。
机器人会不会混进来？
会运行脚本的爬虫可能被记录，但会按特征自动归为“机器人”或“疑似机器人”，默认不显示。偶尔判错可在访客详情页手动修正。
